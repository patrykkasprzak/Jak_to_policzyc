Kalkulator

Jak wpisywać wyniki?

  • Ułamki zwykłe wpisuj używając ukośnika, np. 1/2
  • Pierwiastki kwadratowe zapisuj jako "sqrt", np. $\sqrt{3}$ wpisz jako sqrt(3)
  • Pierwiastki sześcienne i wyższych stopni zapisuj potęgą, np. $\sqrt[3]{8}$ wpisz jako 8^(1/3)
Pytanie: 1/10 Czas: s

Koniec gry!

Twój wynik: 0 / 10

Geometria

Twierdzenie Pitagorasa

W dowolnym trójkącie prostokątnym suma kwadratów długości przyprostokątnych jest równa kwadratowi długości przeciwprostokątnej.

a2 + b2 = c2
Przykład:
Oblicz długość przeciwprostokątnej w trójkącie prostokątnym, jeśli przyprostokątne mają długości 3 cm i 4 cm.

Rozwiązanie:
a = 3, b = 4
32 + 42 = c2
9 + 16 = c2
25 = c2
c = 5 cm

Pole trójkąta

Podstawowy wzór na pole trójkąta wykorzystuje długość jednej z jego podstaw oraz opuszczoną na nią wysokość.

P = ½ · a · h
Przykład:
Podstawa trójkąta ma długość 10 cm, a wysokość opuszczona na tę podstawę wynosi 5 cm. Oblicz pole.

Rozwiązanie:
P = ½ · 10 · 5
P = 5 · 5 = 25 cm2

Twierdzenie sinusów

Stosunek długości boku trójkąta do sinusa kąta leżącego naprzeciwko tego boku jest stały i równy średnicy okręgu opisanego na tym trójkącie.

a / sin(α) = b / sin(β) = c / sin(γ) = 2R
Przykład:
W trójkącie bok o długości 6 leży naprzeciwko kąta 30°. Oblicz promień okręgu opisanego na tym trójkącie.

Rozwiązanie:
a = 6, α = 30°
6 / sin(30°) = 2R
6 / (½) = 2R
12 = 2R
R = 6

Algebra

Wzory skróconego mnożenia

Wzory te pozwalają na szybsze wykonywanie obliczeń algebraicznych, takich jak potęgowanie sum i różnic oraz rozkładanie wielomianów na czynniki.

Kwadrat sumy: (a + b)2 = a2 + 2ab + b2
Kwadrat różnicy: (a - b)2 = a2 - 2ab + b2
Różnica kwadratów: a2 - b2 = (a - b)(a + b)
Przykład:
Zastosuj wzór na kwadrat sumy, aby obliczyć (x + 3)2.

Rozwiązanie:
a = x, b = 3
(x + 3)2 = x2 + 2 · x · 3 + 32
(x + 3)2 = x2 + 6x + 9

Kombinatoryka

Reguła mnożenia

Jeśli pierwszą czynność możemy wykonać na n1 sposobów, drugą na n2 sposobów, a k-tą na nk sposobów, to wszystkie czynności razem możemy wykonać na podaną liczbę sposobów.

N = n1 · n2 · ... · nk
Przykład:
W szafie znajdują się 3 różne koszule oraz 4 różne pary spodni. Na ile sposobów można ubrać zestaw składający się z jednej koszuli i jednych spodni?

Rozwiązanie:
N = 3 · 4 = 12 sposobów

Sześcian sumy i różnicy (Dwumian Newtona)

Szczególne przypadki rozwinięcia dwumianu Newtona dla potęgi trzeciej.

(a + b)3 = a3 + 3a2b + 3ab2 + b3
(a - b)3 = a3 - 3a2b + 3ab2 - b3
Przykład:
Rozwiń wyrażenie (x + 2)3.

Rozwiązanie:
(x + 2)3 = x3 + 3 · x2 · 2 + 3 · x · 22 + 23
(x + 2)3 = x3 + 6x2 + 12x + 8

Trygonometria

Funkcje kąta ostrego

Funkcje trygonometryczne w trójkącie prostokątnym definiuje się jako stosunki długości odpowiednich boków.

sin(α) = a / c
cos(α) = b / c
tg(α) = a / b
Przykład:
Długości przyprostokątnych trójkąta prostokątnego to 6 i 8, a przeciwprostokątnej 10. Oblicz sinus kąta leżącego naprzeciwko boku o długości 6.

Rozwiązanie:
a = 6, c = 10
sin(α) = 6 / 10 = 0.6

Równania trygonometryczne

Równania, w których niewiadoma występuje jako argument funkcji trygonometrycznej. Ich rozwiązania powtarzają się cyklicznie.

sin(x) = y0
Przykład:
Rozwiąż równanie sin(x) = ½ dla kątów z przedziału <0°, 360°>.

Rozwiązanie:
sin(30°) = ½
sin(180° - x) = sin(x)
x1 = 30°
x2 = 180° - 30° = 150°
