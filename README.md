# Jak to policzyć? - Interaktywna Platforma Edukacyjna

Projekt statycznej strony internetowej stworzonej w celach edukacyjnych. Aplikacja łączy w sobie kompendium wiedzy matematycznej z grą poprawiającą czas potrzebny na podstawowe działania matematyczne.

## Funkcjonalności
- **Sekcja Teoretyczna (Akordeon):** Wygodne przeglądanie wzorów i zagadnień z podziałem na kategorie (Geometria, Algebra, Kombinatoryka, Trygonometria).
- **Interaktywne przykłady:** Możliwość samodzielnego rozwiązania problemu przed odkryciem ukrytego rozwiązania.
- **Gra Matematyczna:** Wbudowany silnik quizu z generowaniem losowych równań, licznikiem czasu, walidacją odpowiedzi i systemem punktacji.
- **Galeria (Lightbox):** Możliwość powiększania wykresów i schematów na pełen ekran.
- **Personalizacja:** Przycisk zmiany motywu strony (Jasny / Ciemny).
- **Responsywność (RWD):** Pełne dostosowanie układu do ekranów urządzeń mobilnych oraz komputerów.

## Wykorzystane technologie
- **HTML5:** Semantyczna struktura strony.
- **CSS3:** Stylowanie, Flexbox, Media Queries (Mobile-first / RWD), animacje i przejścia.
- **JavaScript (Vanilla JS):** Logika gry, manipulacja modelem DOM, obsługa zdarzeń i zmiana motywów (bez użycia zewnętrznych bibliotek).
